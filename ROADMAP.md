# Roadmap

## Current foundation

**Being qualified:**
- repository identity and legal texts;
- architecture and governance;
- native documentation;
- dedicated validation tools.

**Domain capabilities and claims:** still empty.

## Capability milestones

1. **The seven record schemas,** each with a golden fixture. The host co-emulation binding comes first, because the hybrid-run path is the first prototype path. Each schema enrols its full quality gates in the change that adds it.
2. **Intake and conversion against open designs.** Each conversion carries its evidence: a formal proof, a simulation reference or a vendor report.
3. **Partition with pinned engines and seeds,** and its reproducibility shown across declared reruns.
4. **The interconnect plan and partition equivalence,** in exact mode first.
5. **Emulation and hybrid runs on virtual platforms.** These need no board.
6. **Physical runs, when a board exists.** Each is bound to one serial-numbered unit, with conditions declared before any trial.

**Built with every surface:**
- strict native quality;
- documentation;
- meaningful coverage;
- the affected benchmarks.

**Each needs its own evidence and approval:**
- cloud FPGA runs;
- equipment actions;
- public activation;
- release.

No availability date is promised. No speed or fidelity advantage is promised either.
